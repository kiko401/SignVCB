| 层级 | 唯一负责 | 不负责 |

## 第一部分：全局设计系统

### 1. 品牌理念与 IP 资产

| 维度 | 规范说明 |
|:---|:---|
| **App 名称** | **默语共鸣** |
| **品牌口号** | 听见你的声音，看见你的世界 |
| **设计理念** | 鹿拥有敏锐的听觉与灵动的身姿，鹿角形如生长的树枝，象征着手语词汇的衍生与儿童语言能力的生长。应用以品牌 IP 为核心，构建一个视觉化、有温度的无障碍沟通与学习空间。 |
| **IP 形象：小鹿「呦呦」** | **配色**：主体为雪白色（`#FFFFFF`），在腹部、耳廓内侧及面颊边缘带有极淡的渐变紫（`#EBE3F8` 过渡至 `#C490F9`），脸颊带有两团圆圆的樱花粉（`#F2C8F7`）红晕。鹿角为浅木色，鹿角尖端会根据交互长出不同的东西。**特征**：耳部佩戴流线型几何耳挂（嫩芽黄 `#E2ED8F`，去医疗化呈现为科技饰品）。**互动定位**：呦呦不是旁观者，是"同桌"，具备多种状态插画。**视线引导法则**：所有页面中呦呦的面部朝向或视线落点，必须指向该页面的核心操作区。 |
| **插画风格定义** | **圆润体块插画风**。无描边，由大色块拼接而成，所有转角极度圆润。动态插画统一使用 Rive 格式，静态使用 SVG 格式。 |

*所有颜色均已在设计系统中注册，严禁使用未定义色值。*

- **辅色 (丁香紫)**：`#C490F9` (渐变辅助、未激活路径、阴影面)

- **点缀 1 (奶酪黄)**：`#FDF37D` (L1 标识、星星奖励、选中高亮、呦呦鹿角)
- **点缀 2 (嫩芽黄)**：`#E2ED8F` (L3 标识、成功状态、呦呦耳挂)
- **强调色 (樱花粉)**：`#F2C8F7` (呦呦红晕、惊喜弹窗)
- **次级背景 (云灰)**：`#F1F5F9` (输入框、占位词卡、次级按钮底)

- **纯白**：`#FFFFFF` (卡片表面、气泡)

### 3. 字体与排印规范

- **字体家族**：全平台原生无衬线 (Android: Roboto/Noto Sans CJK, iOS: SF Pro/PingFang SC)。禁止引入外部字体包。
- **层级定义**：
  - `Display`: 56dp / w700 / 行高 64dp (仅启动页 Slogan)
  - `H1`: 40dp / w700 / 行高 48dp (大标题、跟读大字)
  - `H2`: 32dp / w600 / 行高 44dp (页面标题、句子原文)
  - `Body`: 24dp / w500 / 行高 36dp / 字间距 0.5 (词卡、按钮、气泡正文) —— **儿童交互区最小字号**
  - `Caption`: 16dp / w400 / 行高 24dp (仅家长区辅助说明)
- **阅读呼吸感**：阅读页句子原文行高设为字号的 1.8 倍，字间距增加至 1.5dp。

### 4. 圆角与阴影规范

- **圆角层级**：L1 启蒙期 `28dp`；L2 识字期 `20dp`；L3 表达期 `12dp`；通用胶囊/圆形 全圆角。
- **柔和漂浮阴影**：
  - Resting: `Color(0xFF9067ED).withOpacity(0.08)`, blur: 12, y: 6
  - Lifted: `Color(0xFF9067ED).withOpacity(0.12)`, blur: 20, y: 10
  - Floating: `Color(0xFF9067ED).withOpacity(0.16)`, blur: 28, y: 16

### 5. 动效规范

- **页面转场**：300ms ease-out，Hero 动画用于书籍/节点点击。
- **词卡入场**：200ms 弹性缩放（0.8→1.0）+ 淡入。
- **呦呦状态切换**：400ms crossfade。
- **OOV 脉冲**：1.5Hz 呼吸缩放（1.0→1.1），浅金黄底色循环。
- **错误摇晃**：果冻式左右摇晃 300ms。

## 第三部分：前后端数据契约

### 1. 全量 API 请求参数与响应处理映射表

| 接口路径 | 方法 | 鉴权 | 请求参数 | 响应字段 | 前端 Service |
|:---|:---|:---|:---|:---|:---|
| `/api/v1/auth/register` | POST | 否 | `username, password, age_group, nickname?` | `access_token, token_type, user{id,username,age_group,nickname,avatar_url}` | `AuthService.register()` |
| `/api/v1/auth/login` | POST | 否 | `username, password` | `access_token, token_type, user{...}` | `AuthService.login()` |
| `/api/v1/app_config` | GET | **否**（匿名公共接口） | - | `enable_stream_masking, show_oov_map, show_nmm_hints, sse_timeout_ms` | `ConfigService.fetch()` |
| `/api/v1/asr_and_rewrite` | POST | 是 | `file(音频), context` | SSE 流 | `ChatService.asrAndRewrite()` |
| `/api/v1/rewrite` | POST | 是 | `text, context` | SSE 流 | `ChatService.rewrite()` |
| `/api/v1/tts` | POST | 是 | `text, speed` | `audio_url` | `ChatService.tts()` |
| `/api/v1/suggest_reply` | POST | 是 | `text, context` | `suggestions[]` | `ChatService.suggestReply()` |
| `/api/v1/normalize_options` | POST | 是 | `text, context?` | `options[]` | `ChatService.normalizeOptions()` |
| `/api/v1/log_mismatch` | POST | 是 | `original_text, failed_options[], context?` | `status` | `ChatService.logMismatch()` |
| `/api/v1/reading/books` | GET | 是 | `age_group` | `books[]{id,title,age_group,cover_url,difficulty}` | `ReadingService.getBooks()` |
| `/api/v1/reading/content` | GET | 是 | `book_id` | `book_id, sentences[]{index,original,sign_text,alignment_ops[]}` | `ReadingService.getContent()` |
| `/api/v1/practice/question` | GET | 是 | `level, type` | `id, level, type, mode?, image_urls[], text?, choices[], scrambled[], target_text?`（v3.3 强类型，按 type 取对应字段） | `PracticeService.getQuestion()` |

## 第四部分：核心业务流程实现全链路 SOP（前端操作手册）

### first_pass 透传契约（v3.3 补全，三组联调唯一真源）

> 1. **算法必须生成 `first_pass` 事件**。流水线 Step 1 分词 + OOV 检测后立即 yield `first_pass`，是流水线的固定动作，**不允许跳过**。
> 2. **后端必须透传 `first_pass` 事件**。`ChatService.stream_rewrite` 拿到的 `(event_name, event_data)` 原样 yield，不允许过滤、不允许按 `ENABLE_STREAM_MASKING` 裁剪。
> 3. **前端负责表现**。`ENABLE_STREAM_MASKING=true` 时给 OOV 词卡加脉冲动画，`false` 时不加——但**后端永远会下发 `first_pass` 事件**。同理 `SHOW_OOV_MAP=false` 时 `refined_pass.oov_map` 填空字典、`SHOW_NMM_HINTS=false` 时 `nmm_hints` 填空字典，后端仍下发，前端应判断后跳过渲染。
> 4. **不能依赖后端过滤作为前端默认状态**。所有前端状态机代码必须假设事件流是完整的，过滤逻辑只在前端 UI 层处理。

### 流程 1：双向沟通流 SSE 流式渐进渲染

**触发场景**：用户长按麦克风录音后松手，或在文本输入框输入后点击发送。

**实现步骤**：

1. **发起请求**：
   - 语音模式：`AudioCollector` 录制 WAV/16k 音频 → 调用 `ChatService.asrAndRewrite(file, context)` → 进入 SSE 监听。
   - 文本模式：调用 `ChatService.rewrite(text, context)` → 进入 SSE 监听。
   - **同时启动 8 秒超时计时器。**

2. **接收 `preheat` (T=0s)**：
   - 收到 `SseEvent(type: 'preheat', data: {'original': '我吃苹果'})`。
   - `ChatViewModel` 在左侧列表追加一条 `ChatBubble`。对 `original` 按空格分词，生成多个 `WordCardData(state: CardState.placeholder)`。末尾追加 `Yuyu_Thinking` 动画数据。
   - **v3.1 文本输入场景**：后端 `/api/v1/rewrite` 直接下发 preheat（original 为用户输入文本）。
   - **v3.1 语音输入场景**：后端先下发 preheat（original 为空字符串），ASR 完成后再下发 preheat（original 为 ASR 结果）。前端第一次 preheat 显示"正在听..."，第二次 preheat 替换为实际文本。

3. **接收 `first_pass` (T=0.5s)**：
   - 收到 `SseEvent(type: 'first_pass', data: {'text': '我 吃 东西', 'oov_status': true})`。
   - **v3.1 修复**：使用 `data.text.split(' ')` 获取词列表（而非 `data.tokens`）。
   - `ChatViewModel` 将所有 `WordCardData` 状态从 `placeholder` 变为 `normal`。
   - 若 `oov_status=true`，根据 `enable_stream_masking` 开关决定是否给所有词卡添加脉冲动画（实际 OOV 词在 refined_pass 的 oov_map 中标识）。
   - 移除 `Yuyu_Thinking`，追加 `Yuyu_Nodding`。

4. **接收 `refined_pass` (T=2s)**：
   - 收到 `SseEvent(type: 'refined_pass', data: {'text': '东西 我 吃', 'oov_map': {'苹果':'东西'}, 'nmm_hints': {'2':'NEGATION'}, 'alignment_ops': [...]})`。
   - `ChatViewModel` 根据 `alignment_ops` 对词卡执行位移/删除/插入动画。
   - **v3.1 修复**：根据 `oov_map.values` 判断哪些词卡是降级词（refined_text 中的词已是降级词），给这些词卡设置 `CardState.degraded` 状态（浅金黄底 + 脉冲动画）。
   - 根据 `nmm_hints` 在对应位置词卡上方叠加 NMM 标识。**v3.1 修复**：`nmm_hints` 值为字符串标识（`NEGATION`/`QUESTION`/`PAUSE`），前端映射为 emoji：`NEGATION`→🚫，`QUESTION`→❓，`PAUSE`→⏸️。
   - 移除 `Yuyu_Nodding`，追加 `Yuyu_Signing`。

5. **超时兜底**：
   - 若 8 秒内未收到 `refined_pass`，显示 fallback 文案"没听清哦，再说一次？"，挂载 `Yuyu_Confused`。

6. **错误处理**：
   - SSE 连接断开：自动重连最多 3 次，指数退避（1s/2s/4s）。
   - 收到 `fallback` 事件：显示 fallback 文案。
   - HTTP 错误：按错误码映射处理。

### 流程 2：TTS 音频播放

1. 用户点击 `ChatBubble` 上的喇叭按钮。
2. 调用 `ChatService.tts(text, speed)` → 获取 `audio_url`。
3. `AudioPlayerSingleton.play(audio_url)` 播放音频。
4. 播放期间 `TtsVisualizer` 显示呦呦嘴部开合动画。
5. 切换页面不中断播放（单例模式）。

### 流程 3：意图候选与归一化

1. 用户在 `InputAssemblyTray` 拼装 CSL 词卡后点击发送。
2. 调用 `ChatService.suggestReply(text, context)` → 获取 `suggestions[]`。
3. 在拼装托盘上方显示 `IntentBubble` 候选气泡（最多 3 条）。
4. 若用户点击某条候选，直接发送该 NL 文本。
5. 若用户点击"都不是"，调用 `ChatService.normalizeOptions(text)` → 获取 `options[]`。
6. 显示归一化候选气泡。
7. 若用户仍不选择，调用 `ChatService.logMismatch(original_text, failed_options)` 上报未命中日志。

### 流程 4：阅读跟读

1. 用户在书库页选择书籍。
2. 调用 `ReadingService.getContent(book_id)` → 获取 `sentences[]`。
3. 渲染 `ReadingText` 列表，每句包含 `original`、`sign_text`、`alignment_ops`。
4. 用户点击某句 → 高亮 + 播放 TTS + 显示 `Yuyu_Signing` 动画。
5. `alignment_ops` 用于在原文与手语文之间显示对齐连线动画。

### 流程 5：练习答题

1. 用户在练习地图页选择节点。
2. 调用 `PracticeService.getQuestion(level, type)` → 获取题目。
3. 渲染题目（拼图/田字格/跟读）。
4. 用户作答后调用 `PracticeService.validate(question_id, answer)` → 获取 `correct` 和 `feedback`。
5. 正确：`Yuyu_Cheering` + 星星奖励。错误：`Yuyu_Confused` + 鼓励文案。

### 1. AlignmentOp Dart 类（v3.1 修复：未知 type 抛异常）

```dart
// shared/models/alignment_op.dart
import 'package:flutter/foundation.dart';

enum AlignmentOpType {
  postpone,
  advance,
  delete,
  insert,
}

@immutable
class AlignmentOp {
  final AlignmentOpType type;
  final String word;
  final String? target;
  final int? position;

  const AlignmentOp({
    required this.type,
    required this.word,
    this.target,
    this.position,
  });

  factory AlignmentOp.fromJson(Map<String, dynamic> json) {
    final typeStr = json['type'] as String?;
    // v3.1 修复：未知 type 抛异常，而非默认 postpone
    final type = AlignmentOpType.values.firstWhere(
      (e) => e.name == typeStr,
      orElse: () => throw FormatException('Unknown AlignmentOpType: $typeStr'),
    );

    final word = json['word'] as String? ?? '';
    final target = json['target'] as String?;
    final position = json['position']?.toInt();

    // 字段校验
    if (type == AlignmentOpType.postpone || type == AlignmentOpType.advance) {
      if (target == null || target.isEmpty) {
        throw FormatException('${type.name} requires non-empty target field');
      }
    }
    if (type == AlignmentOpType.insert) {
      if (position == null) {
        throw FormatException('insert requires position field');
      }
    }

    return AlignmentOp(
      type: type,
      word: word,
      target: target,
      position: position,
    );
  }

  Map<String, dynamic> toJson() {
    return {
      'type': type.name,
      'word': word,
      if (target != null) 'target': target,
      if (position != null) 'position': position,
    };
  }
}
```

### 2. SSE 事件类（v3.1 补全完整定义）

```dart
// features/chat/data/sse_event.dart
import 'dart:convert';

/// SSE 事件类型
enum SseEventType {
  preheat,
  firstPass,
  refinedPass,
  fallback,
  error,
  unknown,
}

/// SSE 事件
@immutable
class SseEvent {
  final SseEventType type;
  final Map<String, dynamic> data;

  const SseEvent({required this.type, required this.data});

  /// 从原始 SSE 文本行解析事件
  /// 输入格式：
  ///   event: first_pass
  ///   data: {"text": "我 吃 东西", "oov_status": true}
  ///
  /// v3.2 修复：兼容空 event / 空 data / dataLine 为空字符串的情况。后端 preheat 可下发空 original：{"original":""}，
  /// 此时 dataLine 仍合法，dataStr 为 JSON。空 dataLine 意味着后端主动 yield 了一个仅含 event 的事件，
  /// 为了健壮性补上该分支。
  factory SseEvent.fromRaw(String? eventLine, String? dataLine) {
    final typeStr = (eventLine ?? '').replaceFirst('event:', '').trim();
    final type = typeStr.isEmpty ? SseEventType.unknown : _parseEventType(typeStr);

    final dataStr = (dataLine ?? '').replaceFirst('data:', '').trim();
    Map<String, dynamic> data;
    try {
      data = dataStr.isNotEmpty
          ? (jsonDecode(dataStr) as Map<String, dynamic>)
          : <String, dynamic>{};
    } catch (_) {
      data = {'raw': dataStr};
    }

    return SseEvent(type: type, data: data);
  }

  static SseEventType _parseEventType(String typeStr) {
    switch (typeStr) {
      case 'preheat':
        return SseEventType.preheat;
      case 'first_pass':
        return SseEventType.firstPass;
      case 'refined_pass':
        return SseEventType.refinedPass;
      case 'fallback':
        return SseEventType.fallback;
      case 'error':
        return SseEventType.error;
      default:
        return SseEventType.unknown;
    }
  }
}
```

```dart
/// refined_pass 事件数据
@immutable
class RefinedPassData {
```

```dart
  ErrorInterceptor(this._ref);

  @override
  void onError(DioException err, ErrorInterceptorHandler handler) {
    if (err.response?.data is Map) {
      final apiException = ApiException.fromJson(
        err.response!.data as Map<String, dynamic>,
        err.response!.statusCode ?? 500,
      );

      // v3.2 修复：401 AUTH_INVALID 全局跳登录页，清 Token。
      if (apiException.code == ApiErrorCode.authInvalid) {
        // 异步调用不影响主流程。
        _ref.read(authProvider.notifier).forceLogout();
      }
      handler.reject(apiException);
      return;
    }
    // 网络错误（无响应体），也走 ApiException 统一处理。
    if (err.type == DioExceptionType.connectionError ||
        err.type == DioExceptionType.connectionTimeout) {
      handler.reject(ApiException(
        code: ApiErrorCode.internalError,
        message: '网络连接失败，请检查网络后重试',
        requestId: '',
        statusCode: 0,
      ));
      return;
    }
    handler.next(err);
  }
}
```

### 7. SSE 客户端（v3.1 修复：支持 FormData 参数）

```dart
// core/network/sse_client.dart
import 'dart:async';
import 'dart:convert';
import 'package:dio/dio.dart';
import '../features/chat/data/sse_event.dart';

class SseClient {
  final Dio _dio;

  SseClient(this._dio);

  /// 发起 SSE 请求，返回事件流
  /// v3.1 修复：data 参数支持 Map<String, dynamic> 和 FormData 两种类型
  /// v3.2 修复：connectTimeout 独立设为 10s，receiveTimeout 不设上限（让 SSE 流自然保持）。
  Stream<SseEvent> stream({
    required String path,
    required String method,
    dynamic data,  // Map<String, dynamic> 或 FormData
    Map<String, dynamic>? queryParameters,
  }) async* {
    final response = await _dio.request<ResponseBody>(
      path,
      data: data,
      queryParameters: queryParameters,
      options: Options(
        method: method,
        responseType: ResponseType.stream,
        // v3.2 修复：SSE 不能用 receiveTimeout，否则会被截断。设为 0 表示无限等待（应用层另有 8s 兜底）。
        receiveTimeout: Duration.zero,
        sendTimeout: const Duration(seconds: 30),
        headers: {
          'Accept': 'text/event-stream',
          'Cache-Control': 'no-cache',
          'Connection': 'keep-alive',
        },
      ),
    );

    final stream = response.data!.stream
        .cast<List<int>>()
        .transform(utf8.decoder)
        .transform(const LineSplitter());

    String? currentEvent;
    String? currentData;

    await for (final line in stream) {
      if (line.startsWith('event:')) {
        currentEvent = line;
      } else if (line.startsWith('data:')) {
        currentData = line;
        if (currentEvent != null && currentData != null) {
          yield SseEvent.fromRaw(currentEvent, currentData);
          currentEvent = null;
          currentData = null;
        }
      } else if (line.isEmpty) {
        // 事件分隔符，重置（容忍上个事件未配对到达）
        currentEvent = null;
        currentData = null;
      }
    }
  }
}

final sseClientProvider = Provider<SseClient>((ref) {
  return SseClient(ref.watch(dioProvider));
});
```

### 9. ChatViewModel（v3.1 修复：onFirstPass 使用 data.tokens，onRefinedPass 使用 isFallbackWord）

```dart
// features/chat/application/chat_provider.dart
import 'dart:async';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../data/chat_api.dart';
import '../data/chat_models.dart';
import '../data/sse_event.dart';
import '../../../features/profile/application/config_provider.dart';

enum ChatStatus { idle, loading, streaming, success, error }

class ChatState {
  final ChatStatus status;
  final List<WordCardData> currentCards;
  final String? fallbackText;
  final String? errorMessage;
  final String? yuyuAnimation;

  const ChatState({
    this.status = ChatStatus.idle,
    this.currentCards = const [],
    this.fallbackText,
    this.errorMessage,
    this.yuyuAnimation,
  });

  ChatState copyWith({
    ChatStatus? status,
    List<WordCardData>? currentCards,
    String? fallbackText,
    String? errorMessage,
    String? yuyuAnimation,
  }) {
    return ChatState(
      status: status ?? this.status,
      currentCards: currentCards ?? this.currentCards,
      fallbackText: fallbackText ?? this.fallbackText,
      errorMessage: errorMessage ?? this.errorMessage,
      yuyuAnimation: yuyuAnimation ?? this.yuyuAnimation,
    );
  }
}

class WordCardData {
  final String text;
  final CardState state;
  final String? nmmHint;

  const WordCardData({required this.text, this.state = CardState.placeholder, this.nmmHint});
}

enum CardState { placeholder, normal, degraded, correct, error }

class ChatViewModel extends StateNotifier<ChatState> {
  final ChatService _chatService;
  final bool _enableStreamMasking;
  final int _sseTimeoutMs;
  Timer? _timeoutTimer;
  StreamSubscription? _sseSubscription;

  ChatViewModel(this._chatService, this._enableStreamMasking, this._sseTimeoutMs)
      : super(const ChatState());

  /// 文本输入改写
  Future<void> rewriteText(String text, String? context) async {
    _startStream();
    try {
      final events = _chatService.rewrite(text, context);
      _subscribeEvents(events);
    } catch (e) {
      _handleError(e.toString());
    }
  }

  /// 语音输入改写
  /// v3.1 修复：async 方法
  Future<void> rewriteAudio(File audioFile, String? context) async {
    _startStream();
    try {
      final events = await _chatService.asrAndRewrite(audioFile, context);
      _subscribeEvents(events);
    } catch (e) {
      _handleError(e.toString());
    }
  }

  void _startStream() {
    _timeoutTimer?.cancel();
    state = const ChatState(status: ChatStatus.streaming, yuyuAnimation: 'Yuyu_Thinking');
    _timeoutTimer = Timer(Duration(milliseconds: _sseTimeoutMs), () {
      _handleTimeout();
    });
  }

  void _subscribeEvents(Stream<SseEvent> events) {
    _sseSubscription?.cancel();
    _sseSubscription = events.listen(
      _handleEvent,
      onError: (e) => _handleError(e.toString()),
      onDone: _handleDone,
    );
  }

  void _handleEvent(SseEvent event) {
    switch (event.type) {
      case SseEventType.preheat:
        _handlePreheat(PreheatData.fromJson(event.data));
        break;
      case SseEventType.firstPass:
        _handleFirstPass(FirstPassData.fromJson(event.data));
        break;
      case SseEventType.refinedPass:
        _handleRefinedPass(RefinedPassData.fromJson(event.data));
        break;
      case SseEventType.fallback:
        _handleFallback(FallbackData.fromJson(event.data));
        break;
      case SseEventType.error:
        _handleError(event.data['message'] as String? ?? '未知错误');
        break;
      case SseEventType.unknown:
        break;
    }
  }

  void _handlePreheat(PreheatData data) {
    // v3.1 修复：使用 data.tokens 获取词列表
    final cards = data.tokens
        .map((t) => WordCardData(text: t, state: CardState.placeholder))
        .toList();
    state = state.copyWith(currentCards: cards, yuyuAnimation: 'Yuyu_Thinking');
  }

  void _handleFirstPass(FirstPassData data) {
    // v3.1 修复：使用 data.tokens 而非 data['tokens']
    final cards = data.tokens.map((t) {
      return WordCardData(
        text: t,
        state: CardState.normal,
      );
    }).toList();
    state = state.copyWith(currentCards: cards, yuyuAnimation: 'Yuyu_Nodding');
  }

  void _handleRefinedPass(RefinedPassData data) {
    // v3.1 修复：使用 data.isFallbackWord(t) 判断降级词
    final cards = data.tokens.asMap().entries.map((entry) {
      final idx = entry.key;
      final t = entry.value;
      final isFallback = data.isFallbackWord(t);
      final nmmHint = data.nmmHints[idx.toString()];

      return WordCardData(
        text: t,
        state: isFallback ? CardState.degraded : CardState.normal,
        nmmHint: nmmHint,
      );
    }).toList();

    state = state.copyWith(
      currentCards: cards,
      status: ChatStatus.success,
      yuyuAnimation: 'Yuyu_Signing',
    );
    _timeoutTimer?.cancel();
  }

  void _handleFallback(FallbackData data) {
    state = state.copyWith(
      status: ChatStatus.error,
      fallbackText: data.fallbackText,
      yuyuAnimation: 'Yuyu_Confused',
    );
    _timeoutTimer?.cancel();
  }

  void _handleTimeout() {
    state = state.copyWith(
      status: ChatStatus.error,
      fallbackText: '网络有点慢哦，再试一次？',
      yuyuAnimation: 'Yuyu_Confused',
    );
  }

  void _handleError(String message) {
    state = state.copyWith(
      status: ChatStatus.error,
      errorMessage: message,
      fallbackText: '出错了哦，再试一次？',
      yuyuAnimation: 'Yuyu_Confused',
    );
    _timeoutTimer?.cancel();
  }

  void _handleDone() {
    _timeoutTimer?.cancel();
    if (state.status != ChatStatus.error && state.status != ChatStatus.success) {
      state = state.copyWith(status: ChatStatus.success);
    }
  }

  @override
  void dispose() {
    _timeoutTimer?.cancel();
    _sseSubscription?.cancel();
    super.dispose();
  }
}

final chatProvider = StateNotifierProvider.autoDispose<ChatViewModel, ChatState>((ref) {
  final config = ref.watch(configProvider);
  return ChatViewModel(
    ref.watch(chatServiceProvider),
    config.enableStreamMasking,
    config.sseTimeoutMs,
  );
});
```

```dart
// features/auth/application/auth_provider.dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../data/auth_api.dart';
import '../../../core/storage/token_storage.dart';
import '../../../core/utils/logger.dart';

enum AuthStatus { initial, authenticated, unauthenticated, loading }

class AuthState {
  final AuthStatus status;
  final Map<String, dynamic>? user;

  const AuthState({this.status = AuthStatus.initial, this.user});

  AuthState copyWith({AuthStatus? status, Map<String, dynamic>? user}) {
    return AuthState(
      status: status ?? this.status,
      user: user ?? this.user,
    );
  }
}

class AuthNotifier extends StateNotifier<AuthState> {
  final AuthService _authService;

  AuthNotifier(this._authService) : super(const AuthState()) {
    _bootstrap();
  }

  /// App 启动时恢复登录态：读 Token 与用户信息。
  Future<void> _bootstrap() async {
    try {
      final token = await TokenStorage.getToken();
      final user = await TokenStorage.getUser();
      if (token != null && user != null) {
        state = AuthState(status: AuthStatus.authenticated, user: user);
        AppLogger.d('Auth restored: user=${user['username']}');
      } else {
        state = const AuthState(status: AuthStatus.unauthenticated);
      }
    } catch (e) {
      AppLogger.e('Auth bootstrap failed: $e');
      state = const AuthState(status: AuthStatus.unauthenticated);
    }
  }

  Future<void> login({required String username, required String password}) async {
    state = state.copyWith(status: AuthStatus.loading);
    try {
      await _authService.login(username: username, password: password);
      final user = await TokenStorage.getUser();
      state = AuthState(status: AuthStatus.authenticated, user: user);
    } catch (e) {
      state = const AuthState(status: AuthStatus.unauthenticated);
      rethrow;
    }
  }

  Future<void> register({
    required String username,
    required String password,
    required String ageGroup,
    String? nickname,
  }) async {
    state = state.copyWith(status: AuthStatus.loading);
    try {
      await _authService.register(
        username: username,
        password: password,
        ageGroup: ageGroup,
        nickname: nickname,
      );
      final user = await TokenStorage.getUser();
      state = AuthState(status: AuthStatus.authenticated, user: user);
    } catch (e) {
      state = const AuthState(status: AuthStatus.unauthenticated);
      rethrow;
    }
  }

  Future<void> logout() async {
    await _authService.logout();
    state = const AuthState(status: AuthStatus.unauthenticated);
  }

  /// 401 响应时外部调用：清 Token 并跳登录页。
  Future<void> forceLogout() async {
    await _authService.logout();
    state = const AuthState(status: AuthStatus.unauthenticated);
  }
}
```
